Execution Plan & Agent To-Do

وظایف قابل ویرایش، وابستگی‌ها، اولویت‌ها و شواهد تکمیل. ایجنت موظف است قبل و بعد از هر مرحله برنامه را بررسی و به‌روز کند.

وضعیت «تکمیل‌شده» نیازمند شواهد است. فایل‌های TASK_BOARD.json و EXECUTION_PLAN.md در خروجی ساخته می‌شوند. ویرایش‌های انجام‌شده توسط Codex به‌صورت خودکار با این اپ همگام نمی‌شوند؛ برای بازگرداندن آن‌ها باید JSON جدید را وارد کنی.

User Journey / UAT

مسیر واقعی کاربر، نتیجه مورد انتظار و نتیجه تست روی دستگاه را ثبت کن. FAIL تنها بر اساس مشاهده واقعی ثبت شود.

Skill & Agent Role Bank

انتخاب دستی یا درخواست از JSON مدل · نصب ایمن فایل‌های دستورالعملی در خروجی ZIP · مدیریت اسناد ایجنت.

در این نسخه نقش‌های نمونه قابل انتخاب‌اند. برای ۲۰۰ نقش، فهرست JSON مخزن را از طریق Import کاتالوگ محلی وارد کن؛ هیچ کد خارجی خودکار اجرا نمی‌شود.

فایل‌های قابل مدیریت ایجنت

ویرایش مستقیم، به‌روزرسانی و حذف محتوا؛ اسناد در JSON و ZIP باقی می‌مانند. فایل‌های استاندارد قرارداد همچنان از فیلدهای پروژه تولید می‌شوند.

JSON ورودی می‌تواند شامل bank.skills و bank.roles باشد. این‌ها ابتدا Draft هستند؛ برای اضافه‌کردن خودکار به خروجی باید در همین صفحه بازبینی‌شان کنی.
